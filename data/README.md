# Bibliothèque nutritionnelle

`ciqual-2025.min.json` est une version compacte de la Table Ciqual 2025 de l’Anses.

- Source : https://ciqual.anses.fr/cms/fr/la-table-ciqual-2025
- Jeu de données : https://doi.org/10.57745/RDMHWY
- Licence : Licence Ouverte Etalab 2.0
- Valeurs : pour 100 g d’aliment

Les symboles « inférieur à » de la source sont convertis à la moitié de leur seuil pour fournir une valeur numérique exploitable. Les traces et valeurs absentes sont converties à zéro.
